# Задание 0. Получение API-ключа и настройка окружения

Для выполнения практического задания необходимо настроить локальное окружение для взаимодействия с большими языковыми моделями (LLM) через API.

> **Важное примечание:** В оригинальной инструкции задания предлагается использовать платформу Groq. Однако из-за региональных ограничений (блокировка доступа с IP-адресов РФ) доступ к Groq API невозможен. В данном решении используется **OpenRouter** — агрегатор, предоставляющий доступ к десяткам моделей (включая Llama, Mistral и др.) через OpenAI-совместимый API, с бесплатным тарифом и поддержкой JSON-режима.

# Задание 2. Проблема неструктурированного вывода

На этом шаге демонстрируется, почему обычный текстовый ответ LLM неудобен для программной обработки.

### Что сделано:
1. Отправлен обычный текстовый запрос с просьбой извлечь данные из резюме (без указания формата).
2. Модель вернула текстовый ответ в формате Markdown (с заголовками и списками).
3. Предпринята попытка распарсить этот ответ с помощью `json.loads()`.
4. **Результат:** Код ожидаемо выдал ошибку `Expecting value: line 1 column 1 (char 0)`, так как ответ содержит обычный текст, а не строгий JSON.

### Вывод:
Неструктурированный текст нельзя напрямую использовать в коде. Для автоматизации необходимо принудительно задавать модели формат JSON.

# Задание 3. Решение: JSON-режим (Structured Output)

На этом шаге решается проблема из Задания 2 с помощью принудительного указания формата вывода.

### Что сделано:
1. В системный промпт добавлена четкая инструкция возвращать данные **строго в формате JSON** и описана требуемая схема (поля: name, age, skills и т.д.). (По правилам API, слово "JSON" обязательно должно быть в промпте).
2. В метод `client.chat.completions.create` добавлен параметр `response_format={'type': 'json_object'}`.
3. Модель вернула валидный JSON-объект.
4. С помощью `json.loads()` строка была успешно преобразована в словарь Python (`candidate`).

### Результат:
Данные теперь можно напрямую использовать в коде (обращаться к полям `candidate['name']`, `candidate['salary_from']` и т.д.), что делает пайплайн пригодным для автоматизации.
