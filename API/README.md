# Задание 4. Пайплайн: обработка нескольких резюме

На этом шаге логика извлечения данных была обернута в переиспользуемую функцию и протестирована на батче из 7 разных резюме.

### Что сделано:
1. Создана функция `parse_resume(text)`, которая принимает текст резюме и возвращает словарь Python.
2. Внутри функции реализован механизм **повторных попыток (retry)**. Если модель возвращает пустой ответ или происходит сбой сети, скрипт делает паузу и пробует снова (до 3 раз).
3. Добавлена обработка исключений `RateLimitError` (с паузой 10 секунд) и общих ошибок.
4. Написан цикл, который проходит по списку из 7 текстов резюме, вызывает функцию и собирает успешные результаты.
5. Реализован красивый вывод в консоль с форматированием данных (имя, должность, опыт, зарплата).

### Адаптация под OpenRouter:
* Использован класс `RateLimitError` из библиотеки `openai` (вместо `groq_lib`).
* Для максимальной стабильности и обхода ограничений платных моделей используется умный роутер `openrouter/free`, который автоматически направляет запрос к доступным бесплатным LLM с поддержкой JSON-режима.
* Добавлена задержка `time.sleep(1)` между обработкой разных резюме, чтобы не превышать лимиты запросов.

### Результат:
Скрипт успешно обработал **7 из 7 резюме**. Благодаря механизму retry и роутеру `openrouter/free`, программа устойчива к случайным сбоям бесплатных моделей и корректно извлекает данные (включая зарплаты и форматы работы) для каждого кандидата.

4. **Бонус:** Вместо добавления одной модели, протестировано 5 различных вариантов (включая умный роутер `openrouter/free`), что дало более полную картину доступных бесплатных LLM.
