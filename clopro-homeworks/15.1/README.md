# Задание 1. Yandex Cloud — NAT-шлюз через отдельный инстанс

## Цель

Развернуть в Yandex Cloud две подсети — публичную и приватную — с выходом в интернет из приватной через NAT-инстанс.

## Что сделано

Через Terraform создана VPC `my-vpc` в зоне `ru-central1-a` с двумя подсетями:

- **public** — 192.168.10.0/24, без таблицы маршрутизации;
- **private** — 192.168.20.0/24, привязана к таблице `nat-instance-route`.

В публичной подсети развёрнут NAT-инстанс с фиксированным внутренним IP 192.168.10.254 и статическим публичным IP 130.193.51.64 (образ `fd80mrhj8fl2oe87o4e1`), а также публичная ВМ с публичным IP 158.160.55.192 и внутренним 192.168.10.28.

В приватной подсети создана ВМ `private-vm` с внутренним IP 192.168.20.29, без публичного адреса.

Создана таблица маршрутизации `nat-instance-route` со статическим маршрутом 0.0.0.0/0 → 192.168.10.254 — весь исходящий трафик приватной подсети идёт через NAT-инстанс.

Создана группа безопасности `nat-sg` с правилами SSH (22), ICMP, трафик из 192.168.20.0/24 и любой исходящий.
